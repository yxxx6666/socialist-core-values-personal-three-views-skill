# 02-relationship-analysis.md

## 使用场景

用于分析恋爱、婚姻、暧昧、亲子、友情等关系是否健康，尤其适合识别控制、欺骗、双标、情感绑架和边界侵犯。

## 示例输入

```
请用社会主义核心价值观分析这段关系是否健康。

关系类型：
恋人。

对方的具体行为：
1. 经常查看我的手机；
2. 不允许我和异性朋友正常聊天；
3. 我提出不舒服时，他说这是因为爱我；
4. 他自己却可以和异性朋友正常往来；
5. 如果我反对，他会说我不在乎他。

我感到不舒服的地方：
我觉得自己被控制，但又担心是不是我太敏感。

请重点判断是否存在控制、欺骗、不平等、不尊重边界、不诚信、不公正等问题。
```

## 示例输出

## 1. 关系概况

关系类型：恋人关系。

主要问题：对方以“爱”为理由限制你的正常社交、查看手机，并且在同类行为上对自己和你使用不同标准。

以下判断仅基于当前描述。

## 2. 关键行为拆解

1. 查看手机，涉及隐私和边界；
2. 限制你和异性朋友正常聊天，涉及自由和信任；
3. 用“爱你”解释控制行为，涉及情感合理化；
4. 自己可以做同样的事，却禁止你做，涉及双标；
5. 用“你不在乎我”让你内疚，涉及情感施压。

## 3. 价值观对照

### 自由

恋爱关系不意味着一方失去正常社交和私人空间。

如果对方要求你放弃正常选择，甚至以爱为名限制你，这已经不是健康关心，而是对自由和边界的侵犯。

### 平等

他自己可以和异性朋友正常往来，却不允许你这样做，这是明显不平等。

健康关系应该有一致标准，而不是一方拥有自由，另一方被管控。

### 诚信

恋爱关系需要信任。

长期查看手机并限制社交，说明关系基础不是信任，而是怀疑和控制。

### 友善

真正的友善包括尊重对方感受。

当你表达不舒服时，对方没有理解你的感受，反而用“这是因为爱你”来压过你的感受，这说明同理心不足。

### 公正

同样的行为，对自己宽松，对你严格，是典型双标。

这不符合公正中的“同类行为同等标准”。

### 法治 / 规则感

查看手机涉及隐私边界。即使是亲密关系，也不代表可以随意侵犯对方隐私。

## 4. 判断

这更接近于：控制倾向 + 情感施压。

它不是单纯的“在乎你”，而是把控制包装成爱。

## 5. 三观判断

结论：这段关系中，对方在自由、平等、友善、公正和边界感上存在明显偏差。

这不一定说明对方完全没有感情，但说明他的表达方式和关系观念不健康。

## 6. 建议

1. 明确表达边界：手机、正常社交和个人空间需要被尊重；
2. 看对方是否愿意调整实际行为，而不是只解释；
3. 不要把持续控制理解成深情；
4. 如果对方继续用内疚、威胁、冷暴力让你服从，需要提高警惕；
5. 涉及威胁、暴力、跟踪等情况时，优先保护自身安全并寻求现实帮助。
