# 01-person-analysis.md

## 使用场景

用于分析一个普通人、朋友、熟人、伴侣、亲戚或合作对象的个人三观和靠谱程度。

## 示例输入

```
请用社会主义核心价值观分析这个人的个人三观和靠谱程度。

背景：
我有一个朋友，经常答应别人事情，但从来不兑现。出了问题就推给别人。平时很喜欢让别人帮忙，但别人需要帮助时，他总说自己没空。

具体行为：
1. 多次承诺帮忙，但最后都不做；
2. 出问题后不承认自己的责任；
3. 经常要求别人帮他，却很少回应别人的需要；
4. 喜欢说别人“不够朋友”。

请从诚信、友善、公正、法治、平等、自由、敬业等角度分析。
最后给出判断：三观端正 / 基本正常但有小问题 / 有明显偏差 / 灰色复杂 / 明显不正 / 信息不足。
```

## 示例输出

## 1. 分析对象

你描述的是一个朋友在日常交往中的行为表现。

以下判断仅基于当前描述，不能完整定义这个人，但可以分析这些行为中体现出的价值观倾向。

## 2. 关键行为

1. 经常承诺却不兑现；
2. 出问题后习惯推卸责任；
3. 只要求别人帮忙，自己很少付出；
4. 用“不够朋友”给别人施压。

## 3. 对照社会主义核心价值观分析

### 诚信

反复承诺但不兑现，说明诚信维度存在明显问题。

诚信不是只看一个人说得好不好听，而是看其承诺是否有稳定兑现能力。长期说到做不到，会削弱别人对他的信任。

### 友善

经常要求别人付出，却不回应别人的需要，说明友善不是双向的。

真正的友善包含基本同理心和互相尊重，而不是只在自己需要时才强调关系。

### 公正

只要求别人帮自己，却不承担相应责任，存在明显双标。

这不符合公正中的“公平对待”和“责任对等”。

### 敬业 / 责任感

如果一个人答应了事情却长期不完成，说明责任感较弱。

这不一定代表他整个人完全不好，但说明在合作或承诺事项上风险较高。

### 平等

用“不够朋友”给别人施压，容易把朋友关系变成单方面索取。

健康关系应该是平等的，而不是一方不断要求，另一方不断承担。

## 4. 正向部分

目前描述中没有看到明显正向行为。如果要更准确判断，还需要看他是否在其他情况下愿意付出、是否有承认错误和改正的能力。

## 5. 主要偏差

- 诚信偏差：承诺不兑现；
- 责任偏差：出问题后甩锅；
- 公正偏差：只要求别人，不要求自己；
- 友善偏差：缺少对他人处境的体谅；
- 平等偏差：用关系名义给别人施压。

## 6. 三观判断

结论：三观有明显偏差。

理由：

这些行为不是偶尔一次失误，而是反复出现的交往模式。核心问题在于诚信、责任感、公正感和边界感不足。

但仅凭当前信息，不建议直接判断“这个人彻底不行”。更稳妥的说法是：这个人在朋友关系中的行为存在较高风险，不适合轻易托付重要事情。

## 7. 建议

1. 不要只听他说什么，要看他长期做什么；
2. 涉及金钱、合作、重要承诺时要谨慎；
3. 可以减少无边界付出，明确拒绝不合理要求；
4. 如果对方愿意承认问题并持续改变，可以观察；
5. 如果对方长期只索取不付出，应保持距离。
