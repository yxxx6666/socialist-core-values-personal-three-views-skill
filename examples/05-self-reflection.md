# 05-self-reflection.md

## 使用场景

用于自我反思和个人三观校准，帮助用户从诚信、责任、友善、边界感、公正感等维度发现可改进的具体行为。

## 示例输入

```
请用社会主义核心价值观帮我做一次个人三观校准。

我最近的行为：
1. 经常答应别人事情，但后来拖延；
2. 做不到时，我也不主动说明；
3. 别人催我时，我会觉得烦；
4. 有时候为了避免尴尬，会找借口；
5. 我知道这样不好，但总改不掉。

请指出我做得好的地方、需要改进的地方，以及具体改进动作。语气请客观，不要攻击。
```

## 示例输出

## 1. 你的行为

你提到自己最近有这些表现：

1. 答应别人事情后经常拖延；
2. 做不到时不主动说明；
3. 被催促时感到烦；
4. 有时用借口回避尴尬；
5. 已经意识到这样不好。

以下分析只针对这些行为，不否定你这个人。

## 2. 做得好的地方

你已经意识到问题，并且愿意拿出来分析，这本身就是一种自我修正能力。

一个人三观是否健康，不是看他从不犯错，而是看他能不能看见问题、承担责任、愿意调整。

## 3. 需要校准的价值维度

### 诚信

答应了事情却长期拖延，做不到时也不主动说明，会影响别人对你的信任。

诚信不等于永远做到所有事，而是：

- 能做再答应；
- 做不到及时说明；
- 失约后愿意补救。

### 敬业 / 责任感

如果你答应的是工作、合作、学习任务，那么拖延会影响他人的安排。

责任感的重点不是“我有没有压力”，而是“我是否对承诺产生的后果负责”。

### 友善 / 同理心

别人催你，可能不是故意给你压力，而是对方也在等结果。

如果你只感到烦，却没有意识到对方也被耽误，就说明同理心需要加强。

### 公正

你希望别人理解你的拖延，但别人也有权利获得清晰反馈。

公正意味着不能只考虑自己的难处，也要看到对方的时间和期待。

## 4. 不要自我攻击

这些问题说明你在承诺管理、时间管理和沟通上需要调整，不等于你这个人不好。

真正要改的不是“人格”，而是具体行为模式。

## 5. 改进动作

1. 少承诺  

不要为了面子或避免尴尬随口答应。

1. 答应前先判断  

问自己：我有没有时间？我能不能做到？最晚什么时候交？

1. 提前说明  

如果做不到，不要等别人催，提前说：  

“这件事我今天做不完，最晚明天晚上给你，可以吗？”

1. 给明确时间  

不要说“尽快”，改成具体时间：  

“周三下午 6 点前给你。”

1. 失约后补救  

如果已经拖延，主动承认：  

“这次是我没有安排好，耽误你了。我会在某个时间前补上。”

1. 建立小承诺  

先从小事恢复信用，不要一上来承诺很多大事。

## 6. 三观判断

结论：三观基本正常但有小问题。

理由：

你不是故意伤害别人，也知道问题存在，说明价值底线是正常的。当前主要问题在诚信执行、责任感和沟通习惯上，需要通过具体行动修正。
