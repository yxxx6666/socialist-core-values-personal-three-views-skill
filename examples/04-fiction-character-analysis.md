# 04-fiction-character-analysis.md

## 使用场景

用于分析小说、漫画、短剧、剧本角色是否三观正常，尤其适合检查男主、女主、反派、灰色角色是否存在“把控制包装成爱”“把伤害包装成深情”“把欺骗包装成保护”等问题。

## 示例输入

```
请用社会主义核心价值观分析这个小说男主是否三观正常。

角色设定：
男主是狼人首领，强大、占有欲强，非常爱女主。

关键行为：
1. 因为担心女主离开，他隐瞒了女主真实身世；
2. 他限制女主和外界联系；
3. 他强行替女主决定婚约；
4. 他认为这一切都是为了保护她；
5. 后期女主发现真相后非常痛苦。

请判断这个角色适合做正派、反派、灰色人物还是成长型人物，并指出哪些情节可能导致读者觉得三观崩坏。
```

## 示例输出

## 1. 角色行为概述

角色：狼人首领型男主。

关键行为：隐瞒真相、限制联系、替女主决定婚约，并把这些行为解释为保护。

这是一个典型的“强大深情型角色”，但目前行为中存在明显三观风险。

## 2. 价值观分析

### 正向价值

男主的动机中可能包含保护欲和责任感。

如果外部环境确实危险，他想保护女主，这可以成为角色的正向动机。

但正向动机不能自动洗白错误手段。

### 自由

限制女主和外界联系、替她决定婚约，明显侵犯女主的选择权。

这会让读者觉得女主不是独立的人，而是男主掌控下的对象。

### 平等

如果男主认为自己更强、更懂，所以有资格替女主决定人生，这说明关系并不平等。

爱情关系中的保护不应以剥夺对方主体性为代价。

### 诚信

隐瞒女主真实身世，是重大信息操控。

如果真相会影响女主的人生选择，那么隐瞒就不是简单的保护，而是剥夺知情权。

### 友善

女主发现真相后非常痛苦，说明男主的行为已经造成实际伤害。

真正的友善不只是“我觉得对你好”，还要看对方是否被尊重、是否承受伤害。

### 公正

如果男主犯错却不承担后果，反而让女主轻易原谅，读者容易认为作品在纵容伤害。

## 3. 角色类型判断

该角色更适合定位为：灰色人物或成长型男主。

不建议直接写成完全正派且无需付出代价的深情男主。

## 4. 三观风险

读者可能不适的点：

1. 把控制包装成爱；
2. 把隐瞒包装成保护；
3. 把女主的选择权交给男主；
4. 男主强大就可以越界；
5. 女主痛苦后，男主如果不承担后果，会显得三观崩坏。

## 5. 创作修正建议

1. 让男主明确承认：保护不等于控制；
2. 让女主有愤怒、拒绝、离开的权利；
3. 男主必须付出代价，而不是一句“我是为你好”就被原谅；
4. 增加补偿行为，而不是只靠深情告白；
5. 后期让男主学会尊重女主选择；
6. 如果要保留强占有欲，应把它写成缺陷，而不是美德；
7. 让女主最终的选择来自她自己，而不是被命运或男主强迫。

## 6. 最终判断

结论：三观灰色复杂。

这个男主有保护动机，但行为方式明显越界。只要后续剧情能让他承担后果、真诚改变、尊重女主选择，他可以成为成长型角色；否则容易被读者视为控制型男主，造成三观争议。
