# 03-workplace-analysis.md

## 使用场景

用于分析领导、同事、下属、客户、合作伙伴是否靠谱，适合判断职场中的诚信、公正、责任、规则意识和合作风险。

## 示例输入

```
请用社会主义核心价值观分析这个领导是否值得信任。

具体表现：
1. 经常把团队成果说成自己的功劳；
2. 项目出问题时，把责任推给下属；
3. 私下承诺的奖金和机会，经常不兑现；
4. 对上级很客气，对下属经常羞辱；
5. 工作安排经常临时变化，但不承担后果。

请从敬业、诚信、公正、平等、文明、法治和责任感角度分析，并给出合作风险等级。
```

## 示例输出

## 1. 职场对象

对象：领导。

主要表现：揽功、甩锅、承诺不兑现、对上下级态度不一致、管理缺乏稳定性。

以下判断仅基于当前描述。

## 2. 对照维度

### 敬业 / 责任感

领导的职责不仅是布置任务，也包括承担决策责任、协调资源、保护团队基本公平。

项目出问题时一味推给下属，说明其责任感不足。

### 诚信

私下承诺奖金和机会却经常不兑现，是明显的诚信风险。

在职场中，承诺如果长期没有兑现，会直接破坏团队信任。

### 公正

把团队成果说成自己的功劳，问题却推给下属，属于功劳和责任分配不公。

这会让团队成员感到努力没有被尊重。

### 平等

对上级客气、对下属羞辱，说明其并没有平等尊重不同位置的人。

这体现出明显的权力不对等和人格尊重不足。

### 文明

经常羞辱下属，说明基本职场文明不足。

批评工作可以，但羞辱人格是不健康的管理方式。

### 法治 / 规则感

如果奖金、机会、项目责任有明确规则，却被随意改变或口头承诺替代，说明流程和规则意识较弱。

## 3. 风险判断

合作风险：高。

主要风险：

1. 个人成果可能被侵占；
2. 出现问题时可能被甩锅；
3. 口头承诺可信度低；
4. 长期合作可能消耗情绪和职业安全感；
5. 团队氛围容易恶化。

## 4. 三观判断

结论：在职场场景中，该领导的诚信、公正、平等、文明和责任感存在明显偏差。

不建议把重要职业发展完全押在其口头承诺上。

## 5. 应对建议

1. 重要事项尽量留文字记录；
2. 任务边界、交付标准、责任归属提前确认；
3. 对口头承诺保持谨慎；
4. 保存关键成果和贡献记录；
5. 如果长期被羞辱或不公对待，应考虑内部反馈、转组或寻找替代机会。
