## 这个 Skill 是什么？

本 Skill 将社会主义核心价值观转化为一套普通人能理解、能使用的**个人三观分析框架**。

它可以帮助你分析：

- 一个人是否靠谱；
- 一段关系是否健康；
- 一个行为是否有责任感、边界感、规则感；
- 一个职场对象是否值得信任；
- 一个小说角色是否三观崩坏；
- 一个热点事件反映了什么价值观问题；
- 自己在哪些价值维度上需要校准。

它不是用来骂人、贴标签或审判人格的工具，而是用来帮助用户更清楚地看见：

- 诚信；
- 责任；
- 规则；
- 边界；
- 公正；
- 善意；
- 平等；
- 自由；
- 同理心。

## 核心原则

1. **分析行为，不审判人格**  
    
    只分析具体行为、表达和影响，不根据单一事件给一个人下永久定论。
    
2. **判断倾向，不随便定性**  
    
    使用“有偏差”“风险较高”“信息不足”等程度化表达，避免绝对化判断。
    
3. **区分现实人物和虚构角色**  
    
    现实人物谨慎分析，只评价行为；虚构角色可以分析角色功能、人物弧光和三观风险。
    
4. **不把不同观点直接等同于三观不正**  
    
    只有当行为涉及伤害、欺骗、控制、越界、违法、甩锅、双标等问题时，才进入价值观分析。
    
5. **保持客观、稳妥、理性、正向**  
    
    不使用侮辱性语言，不煽动对立，不鼓励报复。
    

## 分析坐标

本 Skill 将社会主义核心价值观转化为 12 个可分析维度：

| 价值维度 | 个人三观分析含义 |
| --- | --- |
| 富强 | 是否创造正向价值，而不是只消耗他人 |
| 民主 | 是否尊重他人表达、参与和协商 |
| 文明 | 是否具备基本礼貌、秩序感和公共素养 |
| 和谐 | 是否促进良性关系，而不是恶意制造冲突 |
| 自由 | 是否尊重自己和他人的选择与边界 |
| 平等 | 是否平等看待他人，不歧视、不压迫 |
| 公正 | 是否讲公平、不双标、不欺弱 |
| 法治 | 是否尊重规则、契约、法律和隐私边界 |
| 爱国 | 是否有公共责任和共同体意识 |
| 敬业 | 是否认真负责、做好本分 |
| 诚信 | 是否诚实守信、不欺骗、不背刺 |
| 友善 | 是否有善意、同理心和边界感 |

## 适用场景

### 1. 看人

判断一个人是否靠谱，是否有诚信、责任感、边界感和规则意识。

适合问题：

```
这个人经常承诺不兑现，出了问题就甩锅，请分析他的个人三观。
```

### 2. 看关系

分析恋爱、婚姻、友情、家庭关系、同事关系是否健康。

适合问题：

```
对方经常查看我的手机，还说这是因为爱我，请分析这段关系是否健康。
```

### 3. 看职场

判断领导、同事、下属、客户或合作伙伴是否值得信任。

适合问题：

```
这个领导经常揽功甩锅，承诺奖励不兑现，请分析合作风险。
```

### 4. 看角色

分析小说、漫画、短剧、剧本中的角色是否三观正常。

尤其适合检查：

- 把控制包装成爱；
- 把欺骗包装成保护；
- 把伤害包装成深情；
- 把强势包装成负责；
- 把成功包装成正义。

### 5. 看自己

用于自我反思，帮助用户发现自己在诚信、责任、友善、边界感等方面需要改进的地方。

适合问题：

```
我经常答应别人事情但拖延，请帮我做一次个人三观校准。
```

## 如何使用

将 `SKILL.md` 的内容作为 AI Skill、系统提示词或角色指令使用。

用户只需要提供三类信息：

1. **这个人或角色做了什么**；
2. **这些行为影响了谁**；
3. **你想分析的是现实关系、职场场景、自我反思，还是小说角色**。

AI 会基于社会主义核心价值观进行结构化分析，并给出稳妥结论。

## 推荐输入模板

```
请用社会主义核心价值观分析这个人的个人三观。

【背景】
……

【具体行为】
1. ……
2. ……
3. ……

【我想重点分析】
诚信 / 友善 / 公正 / 法治 / 平等 / 自由 / 敬业 / 责任感 / 边界感

请最后给出判断：
三观端正 / 基本正常但有小问题 / 有明显偏差 / 灰色复杂 / 明显不正 / 信息不足。
```

## 输出结构

本 Skill 通常会输出：

1. 分析对象；
2. 关键行为；
3. 对照社会主义核心价值观分析；
4. 正向部分；
5. 主要偏差；
6. 三观判断；
7. 行动建议。

## 判断等级

| 等级 | 含义 |
| --- | --- |
| 三观端正 | 有基本是非感、责任感、诚信、边界感和同理心 |
| 基本正常但有小问题 | 有价值底线，但部分行为需要调整 |
| 有明显偏差 | 某些行为反复出现，已经影响他人或关系 |
| 灰色复杂 | 动机可能有合理部分，但手段或边界有问题 |
| 明显不正 | 持续伤害他人、破坏规则、欺骗操控且不承担责任 |
| 信息不足 | 事实不够，不能做稳定判断 |
