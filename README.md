# 社会主义核心价值观分析个人三观 Skill

这是一个用于“分析行为，不审判人格”的价值观分析 Skill。

它以社会主义核心价值观为坐标，把抽象的价值观转化为普通人能理解、能使用的个人三观分析框架。

本 Skill 可用于分析：

- 一个人是否靠谱
- 一段关系是否健康
- 一个行为是否有责任感、边界感、规则感
- 一个职场对象是否值得信任
- 一个小说角色是否三观崩坏
- 一个热点事件反映了什么价值观问题
- 自己在哪些价值维度上需要校准

## 核心原则

本 Skill 不用于扣帽子、骂人或审判人格。

它遵循以下原则：

1. 分析行为，不审判人格
2. 判断倾向，不随便定性
3. 区分现实人物和虚构角色
4. 不把不同观点直接等同于三观不正
5. 保持客观、稳妥、理性、正向
6. 只基于用户提供的信息分析，不编造事实

## 分析坐标

本 Skill 将社会主义核心价值观转化为 12 个分析维度：

- 富强：是否创造正向价值
- 民主：是否尊重他人表达和参与
- 文明：是否具备基本礼貌和公共素养
- 和谐：是否促进良性关系
- 自由：是否尊重自己和他人的选择
- 平等：是否平等看待他人
- 公正：是否讲公平、不双标、不欺弱
- 法治：是否尊重规则、契约和法律
- 爱国：是否有公共责任和共同体意识
- 敬业：是否认真负责、做好本分
- 诚信：是否诚实守信
- 友善：是否有善意、同理心和边界感

## 适用场景

### 1. 看人

用于判断一个人是否靠谱、是否有诚信、是否尊重规则和边界。

### 2. 看关系

用于分析恋爱、婚姻、友情、家庭关系、同事关系是否健康。

### 3. 看职场

用于判断领导、同事、下属、合作伙伴、客户是否值得信任。

### 4. 看角色

用于分析小说、漫画、短剧、剧本中的角色是否三观正常，是否存在“把控制包装成爱”“把欺骗包装成保护”等问题。

### 5. 看自己

用于自我反思，帮助用户发现自己在诚信、责任、友善、边界感等方面需要改进的地方。

## 使用方式

将 `SKILL.md` 的内容作为 AI Skill、系统提示词或角色指令使用。

用户只需要提供：

1. 这个人或角色做了什么；
2. 这些行为影响了谁；
3. 想分析的是现实关系、职场场景、自我反思，还是小说角色。

AI 会基于社会主义核心价值观进行结构化分析，并给出稳妥结论。

## 示例提问

```
请用社会主义核心价值观分析这个人的个人三观。

背景：
他经常答应别人事情，但从来不兑现；出了问题就推给别人；同时还要求别人必须帮他。

请从诚信、友善、公正、法治、平等、自由、敬业等角度分析。
最后判断：三观端正 / 基本正常但有小问题 / 有明显偏差 / 灰色复杂 / 明显不正 / 信息不足。
```

## 输出结果

本 Skill 通常会输出：

1. 分析对象
2. 关键行为
3. 对照社会主义核心价值观分析
4. 正向部分
5. 主要偏差
6. 三观判断
7. 建议
